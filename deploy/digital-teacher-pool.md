# 数字老师算力池

数字老师模型 `anam-cara-4` 通过现有 API key 和算力组准入；无需给终端用户逐人加入
`DIGITAL_TEACHER_ANAM_USERS` 或发放历史视频分钟。模型问答仍由调用方的智能体连接完成。
交互采用既有数字老师会话 API，不把实时音视频接口伪装成 Chat Completions 模型。

配置 `DIGITAL_TEACHER_ANAM_POOL=true`，`DIGITAL_TEACHER_ANAM_POOL_GROUPS` 为纳入该能力
的算力组 ID。显式关闭的 digital_teacher_plans 行仍优先拒绝访问；密钥、账号、组织
订阅、过期状态继续由既有 API 鉴权和 groupAccessSQL 校验。试用保持每次 90 秒、每个
调用者近 24 小时 5 次，不增加视频扣费或供应商付费额度。

个人连接按现有 WindHub 用户隔离。组织平台使用已有受管连接，在服务端根据已验证的
租户 UUID 和用户 UUID 计算 `sha256("wxm-teacher-v1\n"+tenant+"\n"+user)`，发送
`X-WXM-Teacher-Caller`。只有 `DIGITAL_TEACHER_ORGANIZATION_KEYS` 中登记的服务器连接
密钥 ID 可以携带该字段，且这些连接必须携带有效字段；个人 key 伪造该头会被拒绝。
登记对象是服务连接而非终端用户，连接换 key 后须同步其 ID。客户端只持有自己的
桌面会话；上游连接密钥不返回客户端，不交换不同系统的用户会话。

迁移 244 为老师、私有形象、照片任务和试用会话增加 caller_scope，空值保留历史个人
资料。成员的查找、直接 ID 访问、幂等键、并发限制和每日次数均带此范围。历史收费
会话不向组织成员返回；组织设置不暴露共享账户的分钟账本。后台照片恢复携带原
caller_scope，供应商私有目录只按当前范围授权返回。

Anam SDK 继续只读取一个已创建会话的短期凭据，重新检查原密钥、组和委托连接；
禁用供应商池或撤销组可阻止新连接。停止与同一 Anam ID 的回执恢复沿用原实现。
供应商容量不足会返回实际失败，不会自动购买额度或切到其他供应商。

验证：数字老师 PostgreSQL 集成套件包括双成员同 ID 资料、私有资产、独立并发与
次数、幂等、撤销组、真实迁移及原 Simli/LiveAvatar 账本回归；供应商响应使用固定
替身。真实供应商和客户端网络验收另行记录，不以这些测试替代。

回退：在当前兼容 caller_scope 的版本关闭 ANAM_POOL 并保留停止/回执恢复，组织
平台回退路由。已经写入成员数据后，不直接退回不识别 caller_scope 的旧二进制，
不删除成员资料、不回放历史请求。旧镜像只用于成员数据写入前的部署失败回退。
