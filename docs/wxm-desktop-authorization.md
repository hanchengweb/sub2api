# WindHub 微末智学桌面授权

微末智学在 WindHub 网页注册、登录并确认授权，通过 PKCE 回调自动连接桌面端。客户端 `com.weimozhixue.desktop` 独立于风合智联和手机遥控；不共用其回调或会话。

回调白名单：安装版 `weimozhixue://oauth/callback`；开发预览只允许 `http://127.0.0.1:<1024-65535>/oauth/callback`。拒绝 localhost、其他 IP/域名、用户信息、查询参数、片段和额外路径。该客户端要求随机 state（至少 16 位）、43 位 S256 challenge 和标准 43-128 位 verifier。服务端一次性授权码绑定用户、客户端、回调、state、challenge，五分钟过期。

注册、邮箱验证、登录之间只传递校验后的授权字段。注册成功先回到登录页的授权确认，不直接发放桌面连接。已登录用户从注册入口进入时也展示当前账号与授权确认，可切换账号。网页生成回调时只带 code/state，桌面主进程调用 `/api/v1/auth/desktop/token` 完成换码。网页现有密码、人机验证、二次验证与条款策略继续生效。

微末智学主进程随后读取本人信息，按已有用户 API 创建或复用专用设备连接并加密存储；账号管理刷新令牌用完即撤销。桌面实现及验证见 `D:\wxm-dev\development\personal-account.md`。

验证包括客户端回调白名单、跨客户端隔离、错误 state/verifier/redirect、一次性码重放、注册跳转与桌面取消/关闭/重启重试。不使用生产注册、创建密钥或模型计费作为 UI 测试。

## App 内个人账号页面

桌面端可以在隔离的应用窗口中打开现有注册、登录与授权页面。只有有效的 `com.weimozhixue.desktop` 授权请求，且位于登录、注册、邮箱验证、忘记密码、重置密码或法律协议页面时，才显示固定的“微末智学 / 个人账号”名称、W 标识、标题与图标。非法授权请求、其他客户端及普通 WindHub 网页保留全站品牌；离开这一流程后恢复普通网站图标。名称和图标不接受 URL 自定义。

该入口继续使用 WindHub 原账号、余额与个人服务，登录后仍由桌面既有充值入口办理充值。没有另建用户表、钱包或支付流程。微末智学认证页面隐藏第三方 OAuth 入口；标准 `/login`、`/register` 路由、密码验证和 PKCE 授权协议保持不变。登录、注册、邮箱验证、找回密码及协议跳转只保留已校验的桌面授权字段，返回登录页不带邮箱或重置 token。

有效微末智学入口使用紧凑的 App 内布局：小图标与品牌横排、表单靠上、独立纵向滚动，减少卡片和页脚留白，并限定紫色按钮、链接与输入焦点样式。普通网站继续使用原来的独立网页布局与主题。

协议正文仍使用管理员发布的真实法律文本，只调整页头品牌和返回链接，不能据此认定协议条款已改为微末智学专属条款。认证过程中不显示全站公告或管理员合规弹窗。

页面已适配邮箱验证、忘记及重置密码，但不主动开启这些服务。2026-10-19 只读生产设置显示注册开放，邮箱验证、密码重置、Turnstile、TOTP 和登录协议开关关闭。本次没有改邮件后端：未来启用时，邮件主题和模板仍使用全站品牌，密码重置邮件链接也不携带微末智学上下文；邮件白标需另行完成。
